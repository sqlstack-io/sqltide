---
title: "sqt audit"
description: "Run data-quality audits against current live relations."
---

Run authored SQL audits against current relations:

```bash
sqt audit
sqt audit --select order_items
sqt audit --select +daily_revenue
sqt audit --select pipeline:order_events --json
sqt audit --force
```

Live audit works in both modes. Error-severity failures exit 1; warning failures are reported but do
not fail the command.

Selectors support bare model names, `pipeline:<name>`, and optional leading `+` for upstream
models. Multiple selectors are repeatable. Trailing `+` is not accepted by audit selection.

An audit still in its post-build warmup is reported as deferred instead of run. `--force` runs it
anyway; the result still records the audit's cadence and warmup.

To check a staged deployment before you promote it, run
[`sqt deployment audit --latest`](/cli/deployment). `sqt audit` checks only what consumers read now.
